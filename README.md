# OOP in Java: Lab solutions and Library Management mini-project

Requires JDK 17+ (tested with JDK 21).

    cd lab1 && javac *.java && java Car        # any lab: compile, then run a class that has main

* `lab1` ... `lab10`: one folder per lab; every exercise is a file (or files) named in the lab record.
* `miniproject`: Library Management System.
      cd miniproject && javac *.java
      java LibraryApp            # data folder defaults to ./data
      java LibraryTest           # 28 tests
* `OOP_Java_Lab_Record.docx`: the lab record (explanations, code, real output, class diagram, report).
* `miniproject/class_diagram.png` (source: class_diagram.dot).
* `run_lab.sh <labdir> <Main...>`: compile a lab and run the listed classes.
